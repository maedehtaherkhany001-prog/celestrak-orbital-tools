# CelesTrak Orbital Data Fetcher & Excel Exporter 🛰️

A professional Python toolkit developed for space engineering and orbital mechanics research to fetch, parse, and export space debris and satellite catalog data directly from CelesTrak into structured Excel files (`.xlsx`).

---

## 🚀 Features
- Fetches real-time GP data (CSV/OMM format) from CelesTrak.
- Automatically creates target output directories if they don't exist.
- Exports clean, structured datasets compatible with pandas, openpyxl, and Excel.
